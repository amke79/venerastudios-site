Services

FiveM scripts

Scripts made to order, and later ready-made scripts in the Tebex store. This page explains what you can expect from any Venera Studios resource.

Updated 24 October 2026

Supported frameworks#

Our resources talk to the framework through one bridge layer, so the same script can run on:

  • ESX
  • QBCore
  • Qbox
  • ox_core
  • standalone, without a framework

They work with ox_inventory and ox_target. Each product page or quote states the frameworks, versions and dependencies it was built and tested for. Check them against your server before you buy or accept a quote.

What you get#

  • The resource folder, ready to drop into your server.
  • A commented config.lua for everything a server owner is expected to change.
  • Installation steps, and any database file or item list the resource needs.
  • Translations. New resources ship in English, Bosnian, German, French, Spanish and Dutch.

Installing a resource#

The exact steps come with each product. In general:

  1. Install the dependencies listed for the product first.
  2. Put the resource folder in your server's resources directory.
  3. If the product includes a .sql file, import it into your database.
  4. Add ensure <resource name> to your server.cfg, after its dependencies.
  5. Adjust config.lua, then restart the server.

If anything is unclear, open a ticket. See Support.

How our scripts are built#

  • The server decides. The client only sends what the player wants to do. The server checks it before anything happens: rate limits on every network event, distance checks, and parameterised database queries only.
  • Nothing important is trusted to the client. Money, items, limits and positions are decided on the server.
  • No needless load. No empty loops or heavy threads, even on a full server.

Protected code#

Ready-made scripts may be delivered with parts of the code protected by Cfx.re's asset escrow. Configuration and integration files stay open so you can set the script up for your server. The product page states what is open and what is protected. Trying to remove the protection is not allowed, see Licensing and intellectual property.

Updates#

Fixes for bugs in our code are part of support. Whether a product receives feature updates, and for how long, is stated on the product page or in your quote. We cannot promise compatibility with every future version of FiveM, a framework or another resource.

Licence#

You receive a licence to use the script, not ownership of it. Sharing, reselling or publishing it is not allowed. Custom-built scripts can come with other terms if they are agreed in the quote. See Licensing and intellectual property.
